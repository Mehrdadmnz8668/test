# ISO VPN — Phase 1 Frontend (Next.js App Router + TypeScript + Tailwind CSS)

## Quick Start

```bash
npm install
npm run dev
```

## Production Build Verification

```bash
npm run typecheck
npm run build
```

## Included Routes

- `/` — Landing Page
- `/store` — Dynamic Plan Configurator & Order Summary
- `/login` — RTL Login Page (Phase-1 Demo Flow)
- `/register` — RTL Registration Page (Phase-1 Demo Flow)
- `/dashboard` — Customer Overview Dashboard
- `/dashboard/subscriptions` — Customer Subscriptions Manager
- `/dashboard/orders` — Customer Billing & Order History
- `/dashboard/settings` — Account & Notification Settings
- `/servers` — Server Nodes & Protocols Directory
- `/guide` — Multi-Platform Setup Guides (Android, iOS, Windows, macOS)
- `/faq` — Searchable Knowledge Base & FAQ
- `/admin` — Admin Control Center (Overview, Users, Products, Orders, Coupons, Servers, Settings)
